# Historical Task Records

This directory preserves design notes, implementation steps, and observations
from earlier work. Checkboxes describe their original work sessions and do not
define the current backlog.

- Development rules: [AGENTS.md](../AGENTS.md).
- Current behavior: [requirements](../docs/requirements.md).
- New plans and verification records: [docs/plans/](../docs/plans/).

When resuming an older idea, check current code and tests, then create a dated
plan in `docs/plans/` for any remaining work.
