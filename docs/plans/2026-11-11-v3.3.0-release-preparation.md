# v3.3.0 リリース準備記録

## 到達点

`fix/uv-security-and-dev-workflow` で v3.3.0 の実装・依存更新・文書整理を検証した。
コミット・push・PR・タグ・公開は今回の対象外。
個人用 `config.yml` の既存差分は保持し、検証に使用していない。

## レビュー単位

| 単位 | 主な変更 |
| --- | --- |
| 依存・セキュリティ | `pyproject.toml` の依存下限、`uv.lock`、`3rdPartyLicenses.md` |
| CLI・パッケージ | Hatchling 設定、console script、`--version`、パッケージ版、メタデータ回帰テスト |
| 開発運用・文書 | `AGENTS.md`、README 2 言語、CHANGELOG、現行仕様、履歴入口、旧ツール撤去と ignore |

版はメタデータ・パッケージ・CLI・ロックで `3.3.0` に統一した。
wheel は `analyze_git_repo_loc` だけをパッケージとして収録し、テンプレートと CSS/JS を含む。
sdist はパッケージ・テスト・ビルド用メタデータ・ロック・README・LICENSE を明示的に収録し、
個人設定や作業用ディレクトリを除外する。

## 依存更新と根拠

PyPI の公式 JSON メタデータを照会し、最新安定版の Python 要件と依存制約を確認した。
直接依存の下限は pandas 3.1.1、Plotly 7.1.0、tqdm 4.70.1、PyDriller 2.12、
prompt_toolkit 3.0.53、GitPython 3.2.1 に更新し、pytest は 9.2.0 とした。
Jinja2 3.1.6、PyYAML 6.0.3、pip-licenses 5.5.5、colorama 0.4.6 は最新のまま維持した。

[GitPython 3.2.1 の公開情報](https://pypi.org/project/GitPython/3.2.1/) と
[GHSA-83vg-56qc-22m7](https://github.com/gitpython-developers/GitPython/security/advisories/GHSA-83vg-56qc-22m7)
を確認した。後者は 3.2.0 以下を対象とし、3.2.1 以降を修正版としているため、
ロックだけでなく宣言下限も引き上げた。

PyDriller 2.12 は GitPython の版を固定していない。
GitPython 3.2.1 の `gitdb>=4.0.1,<5` と両立する gitdb 4.0.12、smmap 5.0.3 に解決した。
`uv pip check` で環境全体の互換性を確認した。

## 旧仕様の照合と移管

旧仕様ツリーは現行仕様群と archive の変更履歴だけで、未アーカイブの変更はなかった。
必要な契約は [requirements.md](../requirements.md) に移管した。

| 旧仕様の領域 | 現行コード・検証の照合先 |
| --- | --- |
| CLI、YAML、複数リポジトリ | `cli_args.py`、`config/yaml_config.py`、`test_init_config.py`、`test_doctor.py` |
| 解析・期間・言語・集計 | `analysis/git_repo_loc_analyzer.py`、`analysis/analysis_helpers.py`、関連テスト |
| キャッシュ・差分解析 | `git_repo_loc_analyzer.py` のメタデータ互換性・HEAD 判定とキャッシュ回帰テスト |
| リモート・認証 | `remote/remote_repos.py`、`remote/remote_auth.py`、`test_remote_repos.py` |
| 出力・Markdown | `__main__.py`、`reporting/markdown_summary.py`、一時リポジトリ解析 |
| HTML・タグフィルター | `reporting/html_report.py`、`templates/report.html.j2`、`test_html_report.py` |
| 表示抑止・進捗・並列上限 | `test_progress_warnings.py`、`test_runtime_errors.py`、解析 runner |
| ランタイム・依存管理 | `pyproject.toml`、`uv.lock`、`test_project_metadata.py`、クリーン環境検証 |

CLI の位置引数と廃止済みフラグ、requirements.txt 前提の手順は現行仕様に置き換えた。
期間差分比較は archive の提案であり、現行 CLI に対応する引数・実装がないため、
実装済みとも今回の残作業ともしていない。
旧実装順序文書で未完了だった表示・進捗項目は現行コードと回帰テストを確認して整理した。
HTML フィルターはテーブルだけを変更し、チャートは各タブの全データを使う契約を維持する。

`.serena/project.yml` のローカル差分は削除前に Git 管理外の
`out/v3.3.0-verification/retired-project-config.patch` に保全した。
旧ツールへの運用参照は除去し、再生成ディレクトリは ignore に追加した。
`tasks/` は履歴資料として残し、新しい計画の入口を `docs/plans/` に統一した。

```shell
uv export --frozen --format requirements-txt --no-emit-project --no-hashes \
  --output-file out/v3.3.0-audit-requirements.txt
uvx pip-audit --requirement out/v3.3.0-audit-requirements.txt --no-deps \
  --disable-pip --format json --output out/v3.3.0-audit.json
```
